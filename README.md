# ☕ Coffee Shop Sales Analysis

## 📊 Project Overview

This project analyzes Coffee Shop sales data to uncover actionable business insights related to sales performance, customer behavior, product demand, and store operations.

Using transaction-level sales data, the analysis identifies revenue trends, peak operating hours, best-selling products, store performance comparisons, and seasonal patterns that can support data-driven decision-making.

The project demonstrates practical data analytics skills including:

- Data Cleaning
- Data Transformation
- Exploratory Data Analysis (EDA)
- KPI Development
- Dashboard Design
- Business Intelligence Reporting

---

## 🎯 Business Objectives

The primary objectives of this analysis are:

- Analyze overall sales performance.
- Identify top-performing products and categories.
- Compare sales across store locations.
- Understand customer purchasing trends.
- Discover peak sales hours and high-traffic periods.
- Evaluate monthly growth and seasonality patterns.
- Generate actionable recommendations for business improvement.

---

## 📂 Dataset Information

The dataset contains transaction-level sales records from multiple coffee shop locations.

### Key Fields

| Column | Description |
|----------|-------------|
| transaction_id | Unique transaction identifier |
| transaction_date | Date of transaction |
| transaction_time | Time of transaction |
| store_id | Store identifier |
| store_location | Store location |
| product_id | Product identifier |
| product_category | Product category |
| product_type | Product type |
| product_detail | Product name/detail |
| transaction_qty | Quantity sold |
| unit_price | Price per unit |
| Total_bill | Total sales amount |
| Month Name | Transaction month |
| Day Name | Day of week |
| Hour | Hour of transaction |

## 📌 Key Insights

Some key insights generated from the analysis include:

- Identification of peak revenue periods.
- Recognition of high-performing store locations.

---

## 🚀 Business Recommendations

Based on the analysis:

1. Increase inventory for top-selling products.
2. Schedule additional staff during peak hours.
3. Launch promotions during low-performing periods.
4. Expand successful product categories.
5. Replicate best practices from top-performing locations.
